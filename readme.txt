IMPORTANT :
1. Ceci est une version de préparation. Les cartes de démonstration ne sont pas de vraies actualités.
2. Le formulaire de contact ne transmet aucun message tant qu'il n'est pas connecté à un service ou à une adresse.
3. La publication autonome n'est PAS encore configurée. Il faudra connecter le dépôt GitHub à Netlify puis installer/configurer un CMS. Ne publiez pas de contenus sensibles dans cette maquette.
4. Compléter les mentions légales et la politique de confidentialité avec des informations exactes et adaptées à la situation réelle avant le lancement public.
5. Les pages de contenu individuel devront être générées par le CMS ou ajoutées à partir du modèle d'article.
6. Pour déployer sur Netlify Drop : décompresser l'archive, puis déposer le contenu du dossier du site dans la zone de déploiement. Attention : cela remplace la version publiée. Faites la configuration et les tests avant de mettre en ligne.
